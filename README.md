# 티키토키 연속 재생

레벨별 영상 25개를 선택해 순서대로 재생하는 정적 웹 페이지입니다. 제목과 영상 ID는 티키토키 원본 페이지 `VSK1213`–`VSK1240`에서 확인했고, 제목이 같은 3개 영상은 먼저 나온 항목만 남겼습니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 `http://localhost:8765`를 여세요.

```sh
python3 -m http.server 8765
```

모바일·iPad에서는 HTTPS로 호스팅하면 홈 화면에 앱으로 설치할 수 있습니다. `localhost`에서도 PWA 동작을 확인할 수 있습니다. 화면과 이미지는 캐시되지만 Vimeo 영상 재생에는 인터넷 연결이 필요합니다.

## 사용

레벨 탭에서 영상을 고른 뒤 목록 아래의 **선택 영상 재생**을 누르세요. 모바일·패드에서는 재생목록이 왼쪽으로 접히며, 화면 왼쪽 손잡이로 다시 열 수 있습니다. 재생 횟수와 삭제한 영상 복원은 목록 상단의 **설정(⚙)** 버튼에서 찾을 수 있습니다. 선택한 영상은 목록 순서대로 이어집니다. 재생 횟수는 1·2·3·5·10회 또는 계속 반복을 선택할 수 있습니다. **선택 삭제**로 목록에서 영상을 숨기고 **삭제한 영상 복원**으로 되돌릴 수 있습니다. 선택·삭제 상태와 반복 횟수는 이 브라우저에 저장됩니다.
